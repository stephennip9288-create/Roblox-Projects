# Dead Signal Batch 2 audio audition

Start with **UPLOAD-INSTRUCTIONS.md**. Play files directly, or open **LISTEN.html** after extracting this ZIP. It includes ten original music candidates in WAV and OGG formats, their exact event mappings, a return CSV and rights/provenance notes. You only need to upload one format per accepted candidate.

These tracks are for owner review and are not yet audible in Dead Signal. MAIN must apply reviewed asset mappings and integrate the audio source before an authorized candidate can use them. Full gameplay listening remains a separate acceptance step. Six physical recording requests are listed in **RECORDING-REQUESTS.csv**; those recordings are not included. Existing approved Batch 1 sounds do not need to be uploaded again.

Keep any row you reject or have not reviewed marked false. Return accepted IDs, review/access status and permission evidence to MAIN using **UPLOAD-RETURN.csv**. No new IDs or approvals are prefilled, and no publication is performed by this package or its helper scripts.
