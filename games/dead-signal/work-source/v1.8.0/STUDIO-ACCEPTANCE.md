# Engine acceptance — v1.8.0

None of these tasks was executed in this environment. Use disposable Studio test sessions and record actual observations. Mobile controls testing is postponed.

1. Open each of the three match files and press Play. Confirm admission, Preparing HUD, movement/fire and local floor support. The loading screen must fully cover the viewport, remain still, then disappear without leaving artwork over playable input. Check Dispatch arrival, travel failure/rejection and a slow connection in a published test experience.
2. Use server Command Bar: `local D=require(game.ServerScriptService.DeadSignalServer.Diagnostics); D.openAll(); D.pursuit("Shambler")`. Run across at least three rooms, through each diagonal route and up/down every gallery. Repeat for Runner, Hound, Crawler and Warden. Log `D.status()` before/after; record stalls, replans, recoveries and retirements. Test with closed gates as well. An ordinary zombie retiring is a failsafe, not a passing pursuit result.
3. In Start Server with two and four players, separate survivors, down/remove a target and revive/rejoin. Every eligible enemy must continue hunting and switch invalid targets promptly. Attack checks must not hit through walls or between floors.
4. Crowd a corridor and doorway with many NPCs. Bodies must collide with each other and both R6/R15 operators, without permanent jams, climbing onto one another, flinging or passing through. Inspect the agent navigation overlay for each body size. Check the underside of galleries with the Warden.
5. Eliminate each type naturally. Use `D.ragdoll("Hound")` for a quick extra death view. Check current-pose transitions, head/limb attachment, falls on stairs and gallery edges, slow/airborne corpses remaining dynamic, quiet settling and cleanup after 30 seconds. Corpses must not block bullets or pin survivors.
6. Inspect all twenty weapons in hip fire, ADS, reload, recoil and third person. Pay special attention to receiver/stock/handguard seams, Kestrel and Longwatch imported geometry, scope visibility and muzzle flashes. Verify the muzzle remains outside the character and close-wall firing cannot damage through the wall.
7. Buy gates in several orders. Check every machine, wall buy, fuse/frequency panel, trap, box and radio from a reachable standing position. Traverse every polygon corner and both diagonal flanks without jumping. Try props, railings and windows for unreachable safe spots. Clear all waves and test boss/extraction/boarding/return.
8. Run solo and 2/3/4-active-player rounds 1, 5, 10 and 15. Record clear times, ammunition pressure, player damage/downing, active enemies, path failures and frame/server timings. Do this before changing health/damage to compensate for the old navigation defects.
9. Review lighting, texture permissions, hound/limb seams, ragdoll movement and the quality bar in Roblox itself. Current model work reuses the existing art; the full graphics/art target remains open. Profile dense waves and the decorative part count on the intended hardware.

Studio helpers are gated by `RunService:IsStudio()`. Existing production saves and place configurations are retained. Publish only after review to the matching existing destinations; no publication was performed as part of this delivery.
